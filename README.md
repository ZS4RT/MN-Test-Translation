# MN-Test-Translation

## What is does?
    converts en I10n Files into gl_ES format

## What was used?
    Node.JS
    ElectronJS
    Vanilla Javascript
    Html/CSS

## How Its Done? 
    I used NodeJS's File system module to read in each path 

    Match Key value pairs 
    
    Apply Random unicode characters to value
    
    Write Everything to a new file with path basename and gl_ES format.  
    
    Create an Electron Application with a button to browse Directory"
